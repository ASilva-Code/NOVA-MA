# NOVA - MA

**NOVA - MA** é um projeto acadêmico desenvolvido com o objetivo de colocar em prática os conhecimentos adquiridos em **HTML**, criando um site completo do zero utilizando apenas essa linguagem de marcação.

O projeto consiste em uma plataforma temática de **animes e mangás**, reunindo páginas com informações sobre diferentes obras, episódios, capítulos e uma área de newsletter.

---

## 📖 Sobre o projeto

A proposta da atividade era desenvolver um site utilizando **apenas HTML**, sem a utilização de frameworks ou outras tecnologias para a construção da estrutura das páginas.

Um dos principais requisitos era que o projeto possuísse **no mínimo 5 páginas completas e conectadas entre si**, permitindo a navegação entre diferentes áreas do site.

Para cumprir a proposta, foi criado o **NOVA - MA**, um site inspirado em plataformas de animes e mangás.

---

## 🎯 Objetivo

O principal objetivo deste projeto foi praticar e consolidar conhecimentos relacionados à estruturação de páginas utilizando HTML, incluindo:

* Estrutura básica de documentos HTML;
* Organização e hierarquia de conteúdo;
* Navegação entre diferentes páginas;
* Utilização de links internos e externos;
* Inserção de imagens;
* Incorporação de conteúdos multimídia;
* Criação de tabelas;
* Construção de formulários;
* Uso de elementos semânticos;
* Organização de páginas com diferentes tipos de conteúdo.

---

## 🎌 Funcionalidades

O **NOVA - MA** conta com diferentes áreas relacionadas ao universo dos animes e mangás.

### 📺 Animes

Páginas dedicadas à apresentação de animes, contendo informações como:

* Título;
* Sinopse;
* Informações sobre a obra;
* Temporadas;
* Episódios;
* Imagens;
* Área para visualização de alguns episódios.

### 📚 Mangás

Área destinada aos mangás disponíveis no projeto, apresentando:

* Informações sobre a obra;
* Sinopse;
* Capítulos;
* Imagens;
* Área para leitura ou visualização de alguns capítulos.

### 📰 Newsletter

O site também possui uma página de **Newsletter**, onde o usuário pode preencher seus dados para simular uma inscrição e receber novidades relacionadas a:

* Animes;
* Mangás;
* Novos episódios;
* Novos capítulos;
* Atualizações da plataforma.

> A newsletter possui finalidade demonstrativa, já que o projeto foi desenvolvido utilizando apenas HTML e não possui um sistema de backend para realizar o envio real dos dados.

---

## 🔗 Navegação

As páginas do projeto estão conectadas por meio de links, permitindo que o usuário navegue entre as diferentes áreas do **NOVA - MA**.

A estrutura foi desenvolvida para simular a experiência de utilização de um site real, respeitando a limitação proposta pela atividade de utilizar somente HTML.

---

## 🛠️ Tecnologia utilizada

O projeto foi desenvolvido utilizando:

* **HTML5**

Não foram utilizados frameworks ou bibliotecas externas para a construção da estrutura principal do site.

---

## 💡 Aprendizados

Durante o desenvolvimento do **NOVA - MA**, foi possível praticar conceitos importantes para a construção de páginas web, principalmente a utilização correta das tags HTML e a organização de diferentes páginas dentro de um mesmo projeto.

O desenvolvimento também ajudou a compreender melhor como páginas independentes podem ser conectadas para formar um site completo, além da utilização de elementos como imagens, vídeos, formulários, tabelas e links.

---

## 🎓 Contexto acadêmico

Este projeto foi desenvolvido como parte de uma atividade da faculdade com foco no aprendizado e prática de **HTML**.

O objetivo do projeto é exclusivamente **acadêmico e educacional**, sendo utilizado para demonstrar os conhecimentos adquiridos durante a disciplina.

As imagens, nomes de animes, mangás e demais conteúdos relacionados a obras presentes no projeto pertencem aos seus respectivos autores e detentores de direitos.
